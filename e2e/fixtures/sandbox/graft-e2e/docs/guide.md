# Training log guide

This guide explains how to keep a simple training log.

Every session you complete should be written down the same day. You will
recieve a summary at the end of the week if you keep the log up to date.

Keep easy runs and hard runs in a seperate section so the weekly totals stay
readable. Do not mix the two.

When you are definately going to race, add the race date at the top of the
file. The plan builder reads that date and tapers the load before it.

If a session was cut short, note what occured and why. A short note is
enough; the point is to see patterns later.

Do not skip the rest days. The log is only useful if you rest untill the next
planned session.

Review the log once a month and delete anything that no longer helps you.
