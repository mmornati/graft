# Synthetic eval set

Thirty fictional pull requests in the fictional repository `fictional-org/shop-demo`, with scripted fake-model replies, so that CI runs the whole evaluation harness (`pnpm eval:ci`) offline and without any API key. Nothing here is real code or real data. Each case covers one situation: a plain trivial change (001, 002), a model that must be raised by the floor (003 to 013), the size and visibility rules (014 to 018), prompt injection in different places (019 to 021, 030), out-of-scope edits and a description that lies (022, 023, 026), renames (024, 025, 029) and model failures (016, 027, 028). The expected floor and final class of every case is encoded in `test/unit/eval-synthetic.test.ts`, and `eval/baselines/synthetic.json` is the saved report that CI compares with. To add a case, copy a file in `cases/`, give it the next id (`syn-031-...`) and PR number, keep every secret-looking string out of it, run `pnpm eval run --set eval/synthetic` to look at the result, add the case to the table in the test, and refresh the baseline with `pnpm eval run --set eval/synthetic --save-baseline eval/baselines/synthetic.json` in the same pull request.
