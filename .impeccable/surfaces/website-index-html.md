# Surface brief: public landing page (website/index.html) and its docs skin

Scope: the landing page at the root of GitHub Pages, plus the MkDocs Material skin under /docs/ that inherits its world.
Visitor mode: Persuade (landing); Read (docs).

Audience: tech leads, reviewers and platform/security owners whose repositories receive agent-written pull requests;
prospective Phase 0 pilot teams. Job: understand in seconds what Graft puts on a PR and why it does not trust the
agent's own description. Action: read the docs / open the repository on GitHub; run the offline quickstart.
Proof: the fictional `acme` managed comment from README.md rendered faithfully, the shipped example graft.yaml, the risk
floor rules table from docs/features/intent-cards.md. Constraints: Phase 0 shadow mode said plainly; no metrics,
customers, logos or testimonials; every example labelled fictional.

Decision process: the owner delegated the direction and asked not to be interrupted, so no decision page was served.
The brief pinned the herbarium world; the roll (seed 09d50025, assigned index 4: chain-of-custody evidence record) was
fused into it as a structural raise rather than replacing the pinned material world.

Grounded list, by resonance: 1 herbarium specimen sheet (brief's literal reading); 2 nursery scion-wood tags and grafting
ledger; 3 plant passport / phytosanitary inspection certificate; 4 chain-of-custody evidence record; 5 git branch
notation as an engineering drawing; 6 printer's proof with correction marks; 7 seed-trade catalogue.

Challenger verdicts (fused with Graft's facts, weighed on audience identification and product clarity):
- Bioluminescent wake: declined. Kept: "darkness reclaims everything at rest" -> dark mode is the closed herbarium
  cabinet, and only the active graft line carries light.
- Curved-crease shell: declined. Kept: figures numbered like plates -> every section is a numbered Plate with a caption.
- Oscilloscope bench: declined. Kept: everything measured against one graticule -> the specimen sheet carries a printed
  centimetre scale bar and every plate aligns to it.
- Normalled jackfield: competitive on product clarity (state by stroke pattern), declined on identification. Kept: state
  never by colour alone -> risk classes carry a stamp shape and word as well as a hue.
- Design-annual plate section: competitive on identification. Kept: registration furniture -> corner crop marks on plates.
- Massin stage page: declined. Kept: one voice per speaker -> writer and verifier speak in different type (writer in the
  typed label face, verifier on a pinned determination slip).

## Direction contract

THESIS: Every pull request is a specimen grafted onto your rootstock, mounted on a herbarium sheet with its accession
label (agent, model, task) and a determination slip pinned on by a second botanist (the verifier) who saw only the
specimen. Refuses the gradient SaaS hero with floating UI cards and the cream-serif-terracotta editorial default.

OWN-WORLD: Cool mounting-board ground (grey-green, not cream), iron-gall blue-black ink, one vivid cambium green (the
living layer exposed by a graft cut) for the graft union and primary actions; quarantine-stamp red for `sensitive`,
amber for `logic`, green for `trivial`, each also a stamp shape and word. Typed accession labels in a typewriter mono,
IM Fell display with italic for Latin-style names, Literata for reading. Gummed linen tape strips, corner crop marks,
centimetre scale bar, numbered Plates. Raises: chain-of-custody log (from roll index 4: each handler of the PR signs in
order: author, writer, verifier, rules, policy); state by shape not hue (from Jackfield); plates on a graticule (from
Oscilloscope); dark mode as the closed cabinet (from Plankton).

STORY: The visitor sees a PR mounted as a specimen, learns the four answers, believes the floor cannot be lowered by
trying the floor plate themselves, sees the shadow-mode honesty note, and opens the docs or the repository.

FIRST VIEWPORT: Left 5/12: wordmark, headline "Know what was grafted onto main.", one-line lead, primary green button
"Read the docs", secondary "View on GitHub", shadow-mode tag. Right 7/12: Plate I, a herbarium sheet: rootstock `main`
stem with commit buds, scion `feat/login-rate-limit` joined at a taped graft union, a typed accession label tied on with
string, a determination slip pinned at the corner.

FORM: Herbarium specimen sheet with chain-of-custody raise; brief-pinned (position 1 of my ordered list); seed key 09d50025.
Signature interaction: Plate IV "the floor" — pick changed files and a model opinion; the final class is max(floor, model)
and the needle never drops below the floor. Motion grammar: the graft union "takes" once on load (cambium line draws,
label swings to rest); nothing else loops; reduced motion shows the rested state.
